# Hexo Static Site

Maintain this repository as the published output of Jake's Hexo Blog at `https://jakeuj.github.io/`.

## Repository Context

- The checked-in site was generated by Hexo 3.8.0 and is published from `master`.
- This repository contains rendered HTML and static assets. It does not contain the Hexo source tree, `_config.yml`, theme sources, or a Node package manifest.
- Posts use date-based directories. Some existing paths contain spaces; preserve them unless the user explicitly requests a URL migration.
- `graphify-out/` contains repository analysis artifacts and is not part of the website.

## Editing Guidance

- Treat the checked-in HTML, CSS, JavaScript, and images as the editable source of truth for requests scoped to this repository.
- Preserve existing public URLs, canonical URLs, Open Graph metadata, encoding, and relative asset paths when editing rendered pages.
- Shared navigation, article summaries, taxonomy, and archive content are duplicated across generated HTML files. Inspect the relevant copies and keep them consistent when the requested change affects more than one page.
- Do not introduce Hexo or Node build configuration merely to make a small static-site change. If the user asks for source-level generation, explain that the Hexo source project is absent and identify what input is needed.
- Keep repository documentation at the root unless the user asks to expose it through the site.

## Validation

- Review the changed pages through a local static server when visual or navigation behavior matters: `python3 -m http.server 8000`.
- Check changed internal links and asset paths, especially paths containing spaces.
- Run `git diff --check` and report any validation that could not be performed.
