# Windows 檔案總管緩慢甚至沒有回應

> 首次發表：2023-04-11

---

Windows 11 遇到開檔案很慢的問題

查了一下發現 Windows 10 也同樣有問題

感覺不是個案，紀錄一下解法

## 結論

![結論](dotblogs-97c7eaa0-1681193094.jpg)

1. 打開檔案總管
2. 右上角三個點
3. 選項

![選項](dotblogs-97c7eaa0-1681193151.jpg)

1. 設定以本機開啟
2. 不要顯示最近檔案與常用資料夾…等
3. 清除紀錄
4. 確定

下載 資料夾 緩慢問題

![下載 資料夾 緩慢問題](dotblogs-97c7eaa0-1681193677.jpg)

1. 打開檔案總管
2. 右上角三個點
3. 內容

![內容](dotblogs-97c7eaa0-1681193743.jpg)

1. 最佳化此資料夾 > 一般項目
2. 子資料夾
3. 確定
